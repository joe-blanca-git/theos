Instale o Portal do Aluno na sua tela inicial para acesso rápido e fácil.

Instalar no iPhone

Para instalar o App do Portal do Aluno Theos no seu dispositivo iOS, siga os passos rápidos abaixo:

1
Toque no botão Compartilhar na barra inferior do Safari.
2
Role as opções para baixo e selecione Adicionar à Tela de Início .
